# Setting Up Chrome Force Dark Mode

> I like it dark... haha...

<br>

<br>

### Before getting started

You can apply a Dark theme in Chrome, but if you want to also darken the page background, you can use the method below.

<br>

### Enable Force Dark Mode for Web Contents

#### Enter the following link in the address bar

```
chrome://flags/#enable-force-dark
```

<br>

#### As shown in the image below, select `Enabled` from the Drop-down

![](../kor/images/chrome_force_dark_mode.png)

<br>

#### Relaunch Chrome

<br>

<br>

Let's protect our eyes by using a dark screen ^-^

<br>

*Done!*
