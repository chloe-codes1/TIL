### CSS

- CSS Basic Concepts (definition, usage, etc.)

- Selector-related concepts (priority)
  - The reason selectors had to exist
    - Since HTML structures documents, the concept of selectors was needed to know where in the document to apply styling
  - Priority was needed since styles cascade down like a waterfall
- Units
  - px
  - rem
  - em
- Box model
  - View everything as rectangles
- Block
  - Fills the rest of the total width with margin, blocking everything
- Inline
  - Takes up only its own width without extra margin on the side
- position
  - `absolute` abandons its original position (static) and moves
  - `relative` maintains its original position
- float

#### First class Function

- Characteristics of JavaScript functions
  - Functions can be passed as arguments
  - Functions can be returned
  - Functions can be assigned to variables
- The conditions above are the conditions for first-class objects (first class object / first class citizen) in programming languages!
